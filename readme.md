**Висновок**

DFS намагається дослідити всі вершини на максимальну глибину перед тим, як повернутися назад. Це означає, що алгоритм спочатку йде вглиб, досліджуючи всі можливі гілки перед поверненням назад. Це означає, що алгоритм проходить досить довгий шлях, оскільки вибирає перші доступні гілки, які можуть виявитися не найкоротшими.

**_DFS не шукає найкоротший шлях, а просто заглиблюється якомога далі._**

BFS - працює рівневим способом, він завжди знайде найкоротший шлях у графі. Спочатку він досліджує всіх сусідів стартової вершини, потім їхніх сусідів, і так далі, поки не знайде потрібну вершину.

**_BFS знаходить найкоротшйи шлях (за кількістю кроків), що пояснює значно менший маршрут._**

1. DFS долає довший шлях, бо він занурюється в глибину, перш ніж перевіряти інші варіанти. Це може бути корисним для задач на пошук глибоких зв’язків або перевірку всіх можливих варіантів.
2. BFS долає найкоротший шлях, бо працює рівнями і перевіряє всі можливі варіанти перед зануренням далі. Тому він кориснтй для знаходження оптимальних рішень.
